## Deskripsi Aplikasi

**Fourtix** adalah proyek Tugas Besar berupa layanan *backend* (RESTful API) yang mengkloning platform pemesanan tiket bioskop dan konser seperti **TIX ID** dan **Loket.com**. Aplikasi ini dirancang untuk mendukung sistem pemesanan tiket dengan mekanisme pemilihan kursi spesifik (*seat-based*) maupun pengelolaan stok kuota tiket (*quota-based*).
