## Deskripsi Aplikasi

**Fourtix** adalah proyek Tugas Besar berupa layanan _backend_ (RESTful API) yang mengkloning platform pemesanan tiket bioskop dan konser seperti **TIX ID** dan **Loket.com**. Aplikasi ini dirancang untuk mendukung sistem pemesanan tiket dengan mekanisme pemilihan kursi spesifik (_seat-based_) maupun pengelolaan stok kuota tiket (_quota-based_).
